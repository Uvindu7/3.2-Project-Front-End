Project Overview : 

Liyara is a web-based online clothing shopping platform developed to provide an interactive and convenient shopping experience for retail and wholesale customers. The frontend is developed using React.js and Tailwind CSS to deliver a responsive and user-friendly interface. It allows customers to explore clothing products, interact with 3D clothing visualizations, and receive smart outfit recommendations based on their selected T-shirts. These features aim to improve product exploration and help customers make informed purchasing decisions.

Features : 

User registration and login interfaces
User profile management
Clothing product browsing
Support for retail and wholesale shopping
Interactive 3D clothing visualization
Smart outfit recommendation system
Responsive and user-friendly interface
Integration with the backend through RESTful APIs

Technologies Used :

React.js
JavaScript
Tailwind CSS
REST API integration
